# PR Ready Checklist for Agent-Executed Work

## Scope and correctness
- [ ] Changes are limited to agreed scope
- [ ] Edge cases and failure paths were considered
- [ ] No unrelated refactors or drive-by changes

## Quality validation
- [ ] Targeted tests pass
- [ ] Required build/lint/test commands pass
- [ ] Manual verification completed for changed behavior

## Safety and security
- [ ] No secrets introduced
- [ ] Dependency/security checks completed when applicable
- [ ] Input handling and authz/authn impacts reviewed

## Reviewability
- [ ] Diff is easy to review and logically grouped
- [ ] Commit messages are clear
- [ ] Final summary includes risks and follow-up items
