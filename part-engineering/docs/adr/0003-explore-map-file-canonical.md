# Explore map is file-canonical with optional tracker mirror

Consuming repos always keep the Explore map at `work/<work-id>/explore-map.md`. An issue-tracker wayfinder map is optional for collaboration when configured; the file stays the handoff source of truth and must point at the tracker when used. `## Handoff to Intent` must be non-empty before `01 Grill`. This keeps Explore portable for repos without GitHub Issues while still binding Community Skill wayfinder workflows.
