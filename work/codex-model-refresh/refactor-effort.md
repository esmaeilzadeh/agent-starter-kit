# Effort extension refactor

Effort resolution is a small independent function, leaving model resolution unchanged. The generator renders all outputs before writing so bad effort input cannot partially rewrite another runtime. Tests run isolated consumer journeys through the public script and do not depend on private resolver structure. No additional abstraction or runtime framework is warranted for this bounded extension.

Known-model defaults and the Verify exception remain data in the Codex binding. Documentation supplies task-fit rationale and usage rather than a second executable routing table. Final independent review and Verify are still required.
