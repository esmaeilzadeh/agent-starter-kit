# Intent: Kit Phases 1–2

## What

Ship a Cursor-first modular AI Engineering Starter Kit (Explore `00` + pipeline `01`–`10`) with pinned Community Skills, thin Cursor binding, and install/upgrade paths.

## Why

Delegate engineering labor with human ownership of intent, policy, and acceptance — without inventing a multi-agent runtime.

## Non-goals

Phase 3 workflow-quality completeness; CI; non-Cursor runtime adapters; vendoring Community Skill bodies.

## Known assumptions

GitHub Issues tracker; skills CLI for prepare; `_ask/` branding.

## Open questions

None for Phases 1–2.

## Human decisions

See wayfinder map #2 and ADRs 0001–0010.
