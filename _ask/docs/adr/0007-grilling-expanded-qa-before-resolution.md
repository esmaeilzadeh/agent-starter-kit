# Grilling requires expanded Q&A before resolution

HITL grilling (kit `01 Grill`, Explore decision tickets, and this repo’s wayfinder grilling) must not resolve on bare A/B/C letters alone. Each **numbered load-bearing** question needs enough expansion—alternatives, tradeoffs, failure modes, and what “recommended” actually does—that the human can refuse with understanding. If the human says “expand” / “describe more,” re-issue that question expanded before accepting an answer. Standing preference: never auto-approve a real decision; expansion is part of making approval meaningful.

Obvious defaults belong on an “I’ll assume…” list, not as numbered questions. **Amended by** [`0016-grilling-load-bearing-and-skill-before.md`](0016-grilling-load-bearing-and-skill-before.md).
